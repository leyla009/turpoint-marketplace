# TurPoint v7 - cover images for the demo tours (on top of v6)

Copy over your project, same paths. No new dependencies.

## Why the cards were blank
The seed you pasted wrote to a column called `image_url`. That column does not exist (schema, API and frontend
all use `photo_url`), so it would have crashed; and even with the right column the cards always put the backend
address in front of the path, which breaks any image that is not an operator upload. Both are fixed.

## What is in the zip
- frontend/public/seed/tour-01.jpg ... tour-20.jpg   the 20 cover images (~2.5 MB total, 4:3)
    * 7 are real photos you already had in public/pictures (tours 1, 3, 7, 9, 10, 13, 19)
    * 13 are illustrations generated by tools/make_seed_covers.py
- frontend/app/lib/photo.ts        one helper that decides where a photo lives:
                                     /uploads/...  -> backend (operator uploads)
                                     /seed/...     -> this app's public folder
                                     https://...   -> used as-is
- frontend/app/components/TourCard.tsx, NewTourContent.tsx and app/(main)/tours/[id]/page.tsx use that helper
- backend/src/db/seedPhotoData.js   the 20 tours (place, category, image) in one place
- backend/src/db/seed.js            now writes photo_url; refuses to run twice on a database that already has tours
                                     (`npm run seed -- --force` overrides)
- backend/src/db/seedPhotos.js      adds images to demo tours already in a database (never touches tours that have a photo
                                     or that an operator created)
- tools/make_seed_covers.py         regenerates the 13 illustrations (needs Pillow + numpy) - not needed at runtime

## One manual step
Add this line to "scripts" in backend/package.json:
    "seed:photos": "node src/db/seedPhotos.js"
Then run `npm run seed:photos` once on each database that already has demo tours (your local one, and Railway's if you
seeded it). A brand-new database only needs `npm run seed`.

## Swapping in a better photo later
Overwrite frontend/public/seed/tour-NN.jpg with your own file (keep the name, aim for 4:3, ~1200x900, under ~300 KB).
Nothing else changes.
